KiliKili Figma-ready UI kit
=============================
Frame size: 390 x 844 px
Font: Inter
Primary: #6A11CB
Pink: #FF4D8D
Orange: #FFB347
Blue: #4CC2FF
Green: #43D17A

Import:
1. Open Figma.
2. Create a Mobile frame (390 x 844).
3. Drag/import each SVG into the canvas.
4. Ungroup imported SVG layers to edit text, vectors, and shapes.
5. Use design_tokens.json for reusable colors, spacing and radii.

Screens:
Splash, Login, Sign Up, Home, Create Post, Profile, Friends, Chat,
Notifications, Reels, Settings.
